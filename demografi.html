Data Demografi Desa

Data pada halaman ini diambil otomatis dari Google Spreadsheet yang dikelola Kantor Desa. Untuk memperbarui data, cukup edit spreadsheet-nya — halaman ini akan otomatis menampilkan angka terbaru tanpa perlu ubah kode.

Form Input Data (Khusus Staf Desa)

Untuk mengisi atau menambah data, staf desa mengisi form berikut. Setiap form disubmit, data otomatis masuk ke spreadsheet dan langsung tampil di grafik atas tanpa perlu buka spreadsheet secara manual.

[Sisipkan embed Google Form di sini — lihat langkah pembuatan di bawah]

Catatan keamanan: form ini untuk input rekap angka oleh staf desa, bukan untuk warga umum memasukkan data pribadi (NIK, dsb) — hindari mengumpulkan data pribadi warga lewat formulir publik di website.

Cara Membuat Form Input + Menyambungkannya ke Halaman Ini

  1. Buka Google Forms (forms.google.com) → buat form baru, judul misalnya "Input Data Demografi Desa Lalosingi".
  2. Buat 3 pertanyaan pendek: Kategori (contoh pilihan: Jenis Kelamin, Usia, Pekerjaan, Dusun, Pendidikan), Sub Kategori (teks bebas), Jumlah (jawaban singkat, angka).
  3. Klik ikon Spreadsheet hijau di tab Responses → "Create Spreadsheet" — Google otomatis membuat Sheet yang terhubung ke form ini.
  4. Buka Sheet yang baru dibuat → File → Share → Publish to web → format CSV → Publish → salin tautannya.
  5. Tempel tautan CSV itu ke SHEET_CSV_URL di bagian bawah file demografi.html (sama seperti sebelumnya).
  6. Untuk menyematkan form ke halaman ini: di Google Forms klik Send → ikon embed (<>) → salin kode <iframe> → tempel menggantikan kotak "[Sisipkan embed Google Form di sini]" di atas.

Alur datanya: Staf isi Form → otomatis masuk Sheet → Sheet ter-publish sebagai CSV → halaman ini otomatis menampilkan grafik terbaru. Tidak perlu sentuh kode lagi setelah tersambung.

Alternatif: Edit Langsung Lewat Spreadsheet

Kalau tidak ingin pakai Form, staf desa juga bisa edit datanya langsung di Sheet:

  1. Buka Google Sheets, buat spreadsheet baru dengan 3 kolom: Kategori, Sub Kategori, Jumlah.
  2. Isi datanya, contoh:
    KategoriSub KategoriJumlah
    Jenis KelaminLaki-laki750
    Jenis KelaminPerempuan730
    Usia0–14 tahun400
    PekerjaanPetani500
    DusunDusun 1300
  3. Klik menu File → Share → Publish to web.
  4. Pilih sheet yang sesuai, format Comma-separated values (.csv), lalu klik Publish.
  5. Salin tautan (URL) yang muncul.
  6. Buka file demografi.html, cari baris SHEET_CSV_URL di bagian bawah, tempel tautan tadi menggantikan tautan contoh.
  7. Upload ulang file ke Netlify. Selesai — setiap kali spreadsheet diedit, halaman ini otomatis ikut berubah (refresh browser untuk lihat perubahan terbaru).

Catatan: kolom "Kategori" boleh diulang (misalnya beberapa baris "Dusun") — halaman ini otomatis mengelompokkan per Kategori dan membuat grafik batang untuk masing-masing.
