Input Data Desa

Halaman ini khusus untuk staf/perangkat desa memasukkan data rekap (demografi, ekonomi, pendidikan, dsb). Setiap kali form ini disubmit, datanya otomatis tersimpan ke Netlify → Forms pada dashboard project Anda (app.netlify.com/projects/lalosinggi/forms) — bisa dilihat, diekspor ke CSV, atau diatur supaya mengirim notifikasi email setiap ada isian baru.

Cara Melihat Data yang Sudah Masuk

  1. Buka app.netlify.com/projects/lalosinggi/forms
  2. Pilih form bernama "input-data-desa" untuk melihat semua isian yang pernah masuk.
  3. Bisa klik tombol ekspor/unduh untuk ambil semua data sebagai file CSV.
  4. (Opsional) Di menu Forms → Settings, bisa diaktifkan notifikasi email setiap ada isian baru, supaya tidak perlu cek manual.

Catatan: form ini baru berfungsi setelah folder website di-upload ke Netlify (Netlify perlu "melihat" kode form ini saat proses upload/deploy, bukan saat dibuka di browser biasa).

Data yang masuk ke Netlify Forms belum otomatis tampil sebagai grafik di halaman Demografi — itu perlu langkah tambahan (Netlify Functions). Untuk saat ini, cara paling praktis: unduh data dari Netlify Forms secara berkala, lalu salin angkanya ke Google Sheet yang sudah tersambung ke halaman Demografi.
